# Правила работы

## Завершение задачи

После каждой завершённой задачи с изменениями в репозитории:

1. Выполнить проверки, соответствующие изменениям.
2. Создать коммит с изменениями этой задачи.
3. Отправить коммит в соответствующую ветку remote через обычный `git push`.

Пользователь разрешил этот порядок постоянно; повторное подтверждение не нужно.
Не включать в коммит незавершённые изменения параллельных задач и секреты.
Не использовать force push. Если изменений нет, пустой коммит не нужен.
Прямое указание пользователя не коммитить или не пушить в конкретной задаче
имеет приоритет над этим правилом.
