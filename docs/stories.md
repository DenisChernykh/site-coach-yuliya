# Загрузка и публикация сторис

Главная страница остаётся статической. При `PUBLIC_DATA_SOURCE=api` браузер
получает опубликованные подборки из `/v1/home` при открытии страницы, а фото
и видео — из `/v1/story-media/:id`. Для браузерных запросов используется
`PUBLIC_API_BASE_URL`; backend должен разрешать origin сайта через CORS.

Список сторис не встраивается в HTML и не использует снимок сборки. После
публикации в CMS достаточно обновить страницу: новые подборки, порядок,
подписи и скрытие сторис доступны без ожидания пересборки, даже если на
момент сборки подборок не было. Сохранённый черновик публичный API не отдаёт.

Во время загрузки, при пустом списке или ошибке запроса весь блок скрыт.
Запрос использует общую политику повторов: один повтор при сетевой ошибке
или `5xx`. Открытый просмотр не обновляется в фоне при возврате фокуса или
восстановлении сети, чтобы не менять слайды во время просмотра.

Остальная главная, заголовок, положение и включение самой секции остаются
статическими. Публикация по-прежнему запускает пересборку для этих данных;
показ опубликованных сторис её завершения не ждёт.

В mock-режиме и на GitHub Pages сохраняется статическое демо без API:
подборки передаются при сборке, запрос отключён, медиа лежат в
`public/stories/`. Изменения CMS не обновляют этот демонстрационный снимок.
Предпросмотр админки показывает переданный черновик через прежний `Stories`.
