# Устройство проекта

## Источники

`yuliya-valishina.pen` — редактируемый источник дизайна. Работать с ним нужно через pen.dev и его MCP; файл нельзя читать и изменять текстовыми инструментами. Его расположение сохраняет относительные пути к изображениям.

`docs/brief.md` — исходное задание без редакционных изменений. Решения по дизайну и состояния контента описаны в `design/README.md`.

`design/screens.json` связывает последовательные номера 00–09 с ID фреймов и PNG экспортами. У шаблона статьи одна пара desktop/mobile; отдельные копии под каждый текст на холсте не создаются.

## Прототип

`design/prototype/navigation.json` хранит для каждой страницы обе версии экрана, размеры, ссылки и якоря. `prototype.js` выбирает вариант по ширине окна и располагает активные области поверх PNG. `prototype.css` оформляет панель превью, фокус и мобильное меню.

Размеры в манифестах — логические размеры фреймов. Экспорт очень длинной мобильной главной ограничен pen.dev до 8192 px по высоте: PNG пропорционально уменьшен до 247 × 8192 px. Проверка допускает только это пропорциональное уменьшение с округлением до пикселя; остальные PNG должны точно совпадать с размерами фреймов.

HTML страницы генерируются `scripts/build_preview.py` и хранятся в Git, поэтому для просмотра достаточно локального HTTP сервера. Статьи доступны по `finding-your-work.html` и `showing-up.html`; это два наполнения одного шаблона. Сохранённые PNG второго наполнения используются только в превью.

Производственная реализация сайта пока не создана. Прототип позволяет согласовать внешний вид и маршруты; отправку форм, видео и интеграции предстоит подключить при разработке.

## Обновление

1. Изменить дизайн через MCP pen.dev и сохранить `.pen`.
2. Экспортировать изменённые экраны в `design/exports/`, сохраняя существующие имена файлов.
3. Если размеры или ссылки изменились, обновить соответствующие записи `navigation.json`.
4. При изменении состава холста обновить `screens.json` и таблицу в README.
5. Выполнить `make build` и `make check`, затем проверить изменённые страницы в браузере.

Изображения, PNG экспорты и сгенерированный HTML включены в репозиторий. Для запуска не нужны генератор изображений, Node.js или установленный pen.dev.
