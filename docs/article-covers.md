# Обложки статей

Обложка выбирается файлом в редакторе статьи. Доступны превью, замена и
описание изображения. Поддерживаются JPG, PNG и WebP до 8 МиБ.

При загрузке обложки сервер:

- проверяет и декодирует изображение;
- исправляет ориентацию по EXIF;
- уменьшает длинную сторону до 2560 пикселей, сохраняя пропорции;
- сохраняет WebP с качеством 90, качественным цветовым субсемплированием и
  прозрачностью без потерь;
- удаляет EXIF и прочие исходные метаданные.

Маленькие изображения не увеличиваются. Кадрирование не применяется.
Повреждённые файлы, многокадровые WebP и изображения больше 64 мегапикселей отклоняются.
Обработка ограничена десятью секундами. При ошибке прежняя обложка статьи
остаётся выбранной. Размер нового файла зависит от исходного изображения:
уже сильно сжатый исходник не обязательно станет меньше.

Хранилище получает готовый WebP, его фактический размер и MIME `image/webp`.
Превью показывает именно сохранённый результат. Оригинал отдельно не
сохраняется. Ранее загруженные файлы не изменяются; для их оптимизации нужно
заново выбрать файл обложки.

Клиент передаёт `purpose: "article-cover"` в существующий защищённый
`POST /v1/admin/story-media`. Без этого признака сохраняется прежнее поведение
загрузок сторис и документов. Публичная ссылка на медиа остаётся постоянной.
