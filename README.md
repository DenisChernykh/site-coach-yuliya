# Сайт Юлии Валишиной

Сайт специалиста с услугами, журналом, формами и системой управления контентом.

## Возможности

- Адаптивные страницы, статьи, фильтры, FAQ и диалоговые интерфейсы.
- Публичная часть на Astro и React, backend и административная панель.
- Управление контентом и SEO, типизированные API-контракты.

## Инженерные акценты

- Полный цикл разработки сайта с редактируемым содержимым.
- Воплощение графического макета в адаптивный интерфейс.
- Связь публичного сайта, CMS, API и процесса публикации контента.

## Стек

React, Astro, TypeScript, TanStack Query, Tailwind CSS, NestJS, Prisma, React Router, Vite, Vitest.

## Навигация по коду

- [admin/](admin/) — административная панель.
- [backend/](backend/) — серверная часть.
- [src/](src/) — исходный код.

- [docs/stories.md](docs/stories.md) — загрузка и публикация сторис.

## Разработка

Инструменты: Node.js 24.18.0, pnpm@11.15.1.

```sh
pnpm install
pnpm dev
pnpm check
pnpm test
pnpm build
```

Параметры окружения перечислены в [.env.example](.env.example), [backend/.env.example](backend/.env.example). Локальные значения задаются вне Git.
