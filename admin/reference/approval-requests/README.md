# Reference implementation из React Starter

Исходный модуль согласований и его OpenAPI сохранены как пример FSD,
query/cache ownership, feature mutations и permission UI.
Продукт использует NestJS coach-site: заявки клиентов, контент, публикация.
Reference не подключён к production routes и не входит в product build.
Полная исполняемая версия остаётся в неизменённом исходном react-starter,
commit 258b4e0a21022fc0894701e52885fd39b40469ee.
